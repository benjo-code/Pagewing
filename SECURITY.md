# Sicherheit / Security

## Deutsch

**Unterstützte Version:** Nur die jeweils letzte veröffentlichte Version bekommt Sicherheitskorrekturen.

**Melden:** Bitte melde eine Sicherheitslücke über das private Melden von GitHub: im Repository den Reiter „Security“ öffnen und „Report a vulnerability“ wählen. Eröffne dafür **nie** ein öffentliches Issue oder einen öffentlichen Pull Request.

**Was melden:** zum Beispiel Fehler, durch die eine manipulierte PDF-Datei Code ausführt oder die App zum Absturz bringt, Umgehungen der Bestätigung externer Links, Fehler beim Schwärzen (Inhalt bleibt in der Datei), Schwächen der Update-Prüfung (Signatur oder Prüfsumme) und Fehler, durch die beim Speichern Daten verloren gehen oder das Original beschädigt wird. Fehler in den mitgelieferten Drittbibliotheken (etwa PDFium) bitte, wenn möglich, auch bei deren Projekt melden.

**Antwort:** Ich antworte nach Möglichkeit zeitnah und bemühe mich um eine Korrektur, kann aber keine Fristen zusagen. Pagewing ist ein Projekt in der Freizeit.

## English

**Supported version:** Only the latest released version receives security fixes.

**Reporting:** Please report a vulnerability through GitHub's private vulnerability reporting: open the "Security" tab of the repository and choose "Report a vulnerability". **Never** open a public issue or pull request for a vulnerability.

**What to report:** for example, a crafted PDF that executes code or crashes the app, ways around the confirmation of external links, redaction flaws (content stays in the file), weaknesses in the update check (signature or checksum), and bugs that lose data on save or damage the original file. Please also report flaws in bundled third-party libraries (such as PDFium) to their projects where possible.

**Response:** I reply as soon as I can and try to fix issues, but I cannot promise deadlines. Pagewing is a spare-time project.
